# command mode

# movement
`hjkl`  movement
`e`  end of word
`w` begin of word
`W` begining of WORD
every movement is also a selection
every time you move the cursor, you are selecting something
`b` back
`f` find  select everything to f
`t` till  select everything till f
`C-d` move half a page down
`C-u` move half a page up
`C-f` move full page down
`C-b` move full page back
`x` select whole, press it again to go select next line
`;` colapse selection to a single character 

# goto mode
`g` goto mode
`gg` goto top
`ge` goto end
`gl` end of line
`gh` begining of line
`gs` fist none blank in begining of line
`<num>G` go to line number
`g<num>g` go to lin number
`gw` mark every word for jumping
`C-o` jump out
`C-i` jump in
`gr` go to reference
`gi` go to implementation
