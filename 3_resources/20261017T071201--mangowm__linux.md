a lightweight feature rich Wayland compositor 

it is based on dwl and is meant to be as light weight as dwl

Philosophy: Lightwight and Fast

animations: for opening, closing, moving, and tag switching???

layouts: scroller, Mater-stack, Monocle, Grid, Deck, with per-tag layouts.

visual effects: blur, shadows, corner radius, opacity

uses tags intead of workspaces allows seperate windows layout for each tag

```conf
# Start the status bar once
exec_once=waybar

# Set wallpaper
exec_once=swaybg -i ~/.config/mango/wallpaper/room.png

# reloads everythig mango is reloaded
exec=bash ~/.config/mango/reload-settings.sh
```
