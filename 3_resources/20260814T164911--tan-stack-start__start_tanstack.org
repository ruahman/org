* loader function

a function that runs on both client and server

load data from a database
#+begin_src typescript
  export const Route = createFileRoute('/products')({
      component: RouteComponent,
      loader: async () => {
  	const products = await getProducts()
  	return products;
      }
  })

  function RouteComponent() {
      const {products} = Route.useLoaderData()

      return <div> {products} </div>
  }
#+end_src

* isomorphism / code execution pattern

you code executes on both the server and the client

TanStack Start runs in two environments

** Server
Node.js runtime with access to file system, database, environment variables

Durring SSR : inital page render on server

API requests

** Client
browser runtime, access to DOM, localStorage

after hydration - client takes over after initial server render

navigation - route loaders run client-side during navigation

let the client takover once website is loaded

* Server functions

create a function that only runs on the server

#+begin_src typescript
  import { createServerFn } from '@tanstack/reac-start'

  export const getData = createServerFn().handler(async () => {
      return { message: 'Hello from server!' }
  })
#+end_src


#+begin_src typescript
  import { createServerFn } from '@tanstack/react-start'

  // when called from client it makes a http het request
  // make a fetch request when on the client
  // if on server then just call database method
  // there server should run this directly
  // the client should make a fetch request
  const serverLoader = createServerFn({ method: 'GET' }).hander(() => {
      return db.query.todos.findMany()
  })

  export const Route = createFileRoute('/')({
      component: App,
      loader: () => {
  	return serverLoader()
      },
  })

  function App() {
      const todos = Route.useLoaderData();
      return <h1>Hi {todos.lenght}</h1>
  }
#+end_src
