* key
| key                | command                             | description                                      |
|--------------------+-------------------------------------+--------------------------------------------------|
| M-RET              | new headline                        | create a new exact copy of headline in next line |
| M-Left             | move headline or table column left  | move headline or table column to left            |
| M-right            | move headline or table column right | move headline or table column to right           |
| M-up               | move headline or table row up       | move headline or table row up                    |
| M-down             | move headline or table row down     | move headline or table row down                  |
| C-u C-c .          | insert datetime                     | insert data time string                          |
| C-c .              | insert timestamp                    | insert time string                               |
| C-c C-l            | insert link                         | insert link                                      |
| C-c C-o            | open link                           | open link                                        |
| C-c C-e            | export                              | export this org file                             |
| M-S <arrows>       | move groups                         |                                                  |
| C-c C-t            | TODO options                        | show options for TODO                            |
| C-c C-c            | check                               | toogle checklist                                 |
| C-c C-d            | deadline                            | add deadline to headline                         |
| C-c C-s            | schedule                            | add schedule to headline                         |
| Shift-Tab          | toogle all headlines                |                                                  |
| Shift-<left right> | move cycle through todos            |                                                  |
| M-org-agenda       | org agenda view                     |                                                  |
| M-org-agenda-list  | list tasks scheduled                |                                                  |

| C-c C-w            | refile                              | move block under another headline                |
| C-c C-z            | log                                 |                                                  |
