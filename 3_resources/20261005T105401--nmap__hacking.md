*nmap* (network mapper) is a tool used by hackers to scan networks or to find live hosts

`nmap -sP 10.7.1.0/24`  check all host in network 10.7.1.0 with subnet 24
it pings them all.  you can use this in your own network

`nmap -sT -p 80,443 10.7.1.0/24`
look for host that have port 80 and 443 open
