CDK compiles to CloudFomation code

need CDK CLI tool

cdk deploy
validate your cdk code
generate cloudformation code
deployment

cdk synth
just does compilation

you can setup Github actions to deploy

construct
a building block in aws

level 1
single resource
CFN Resources (Cloud Foundation Resource)
lowest level construct
give the most power
avoid 90%
it's basically a Cloud Formation resource

level 2
curated constructs
single resource
medium level
sensible defaults
most commonly used

level 3
multiple resources
patterns
they don't directly represent on resource but multiple

Stacks
containers of constructs
a way to organize your resources

App
the collection of the different stacks

cdk depends on aws cli

you can setup unit tests
